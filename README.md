# 🏠 AI Real Estate Legal Contract Advisor

An AI-powered full-stack system that analyzes real estate legal contracts and provides **smart summaries, legal insights, and voice-based interaction** using AI, RAG, and OCR.

---

## 🚀 Overview

This project helps users easily understand complex legal contracts by using Artificial Intelligence.  
It extracts text from documents, analyzes legal clauses, and provides simple explanations using LLMs.

---

## 🧠 Key Capabilities

- 📄 Contract Upload (PDF / Images)
- 🧠 AI Contract Summarization
- 🔍 Legal Clause Analysis
- 💬 AI Chat Assistant (RAG-based)
- 🎙️ Voice Interaction System
- 🇵🇰 Pakistan Property Law Context

---

## 🧩 System Architecture

- **Frontend:** React Native (Expo)
- **Backend:** FastAPI
- **AI Layer:** LLMs + RAG + Embeddings
- **Database:** MongoDB + Vector Search (FAISS)
- **Voice AI:** Whisper + ElevenLabs
